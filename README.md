### Installation

Install the package via [NuGet](https://www.nuget.org/packages/Limbo.FormattingObjects.Html). To install the package, you can use either the .NET CLI:

```
dotnet add package Limbo.FormattingObjects.Html -pre
```

or the NuGet Package Manager:

```
Install-Package Limbo.FormattingObjects.Html -pre
```
